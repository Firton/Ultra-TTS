# Roadmap

Ultra-TTS is an early open-source local TTS GUI and CLI workspace. The roadmap focuses on reliability, documentation, model setup clarity, and maintainability.

## Near term

- Improve Japanese text normalization tests
- Add more backend setup guides
- Add demo screenshots and audio samples
- Improve long-form generation stability
- Add CI for lightweight text pipeline tests
- Improve model license documentation
- Improve Windows, macOS, and Linux launch instructions

## Future

- Package the web app for easier desktop use
- Add more Japanese TTS backend presets
- Add voice/style comparison examples
- Add clearer error messages for missing models
- Add release automation
- Add more regression tests for segmentation and manifest generation
