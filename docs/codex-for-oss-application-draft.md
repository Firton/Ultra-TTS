# Codex for Open Source application draft

This document contains draft text for the maintainer application. Do not submit claims that are not publicly verifiable.

## Repository qualification

Ultra-TTS is an open-source local browser GUI and CLI workspace for running Japanese and multilingual TTS models. It supports local TTS workflows such as LM Studio/Orpheus, Chatterbox, Kokoro, Piper, Dia, and MLX-Audio, including long-form text splitting and multi-speaker generation. I am the primary maintainer and maintain the GUI, backend integration, docs, tests, and releases.

## API credits usage

I would use API credits for OSS maintainer automation: PR review, issue triage, release-note drafting, documentation sync, backend setup docs, regression test generation, and Japanese text normalization/long-form TTS test cases. All outputs would be reviewed by me and validated by CI before release.

## Additional context

Ultra-TTS was developed privately first and recently made public as OSS. Adoption is still early, so I am applying based on ecosystem value rather than existing downloads: it lowers the barrier for Japanese developers, creators, educators, and accessibility-focused users to run local, API-independent TTS workflows. I plan to improve packaging, samples, CI, model setup docs, and release automation.
